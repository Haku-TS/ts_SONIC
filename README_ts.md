# XR Teleoperation 操作手順書

## 0. 事前準備とネットワーク確認
* ロボット、pico、PCのネットワーク接続が正常であることを確認します。

## 1. デバイスの装着とキャリブレーション
* picoおよびモーショントラッカーを装着し、キャリブレーションを完了させます。

## 2. pico側でのアプリ起動
* pico内で「tsXRoboToolkit」アプリを起動します。
* このとき接続IPウィンドウが表示された場合は、IPアドレスが正しいことを確認して接続してください。
* IPウィンドウが表示されなかった場合は、そのまま次の手順へ進んで問題ありません。

## 3. PC側でのスクリプト実行
* PCのターミナルで `run_robot.sh` を実行します。

## 4. ロボットへの接続
* pico内の「tsXRoboToolkit」で接続IPウィンドウが表示されたら、そこに表示されているIPアドレスを確認します。
* なお、手順2で既に接続を完了している場合は、このステップをスキップしてください。

## 5. 通信開始と映像確認
* 画面右上にある「Listen」ボタンを押し、ポート番号が `12345` であることを確認して、カメラ映像が表示されるまで待機します。

## 6. UI画面の表示切り替え
* 右手側のサイドボタンを操作して、カメラ映像を平面表示に切り替えます。この操作によりUI画面が表示されます。

## 7. 操作の開始
* 画面右下に表示されている「Robot Mode」の赤文字の指示に従って、操作を行ってください。
